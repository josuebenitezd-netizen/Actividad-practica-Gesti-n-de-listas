# Una Tienda de barrio necesita un programa de consola para poder contralar el inventario de sus productos

## Descripción:
Este proyecto de inventario de la tienda “La Bola Rosa” nos permite agregar, mostrar, buscar, modificar, 
eliminar, ordenar productos y ver estadísticas de precios y salir.
